# CAPCHAIN

This repository stores the CAPCHAIN Google Form link and the feedback collected from it.

## Google Form

Google Form link:

- Form: [CAPCHAIN Google Form](https://docs.google.com/forms/d/11_oTjSx9bSPpfZpzlaqHeS-DuJ2CQIO0AGaH5udmOKQ/edit)

You can also update [`form/form-link.md`](form/form-link.md) with the final link and any notes about the form.

## Feedback

Feedback can be stored in two formats:

- [`feedback/feedback.csv`](feedback/feedback.csv) for spreadsheet-style responses.
- [`feedback/feedback.md`](feedback/feedback.md) for readable summaries, highlights, and comments.

## Suggested Workflow

1. Create your Google Form.
2. Copy the shareable form link into this README and `form/form-link.md`.
3. Export responses from Google Forms or Google Sheets as CSV.
4. Replace the sample rows in `feedback/feedback.csv`.
5. Add a short summary in `feedback/feedback.md`.

## Privacy Note

Do not commit private information such as phone numbers, email addresses, student IDs, or personal details unless you have permission to publish them.
